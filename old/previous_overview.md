# 전체 진행 현황 — 완료한 작업과 남은 검토

**최신 분석:** [V3 검증 재설계](../docs/nested_v3.md). 기존 시험 동 제외, 학습 전용 EDA, 중첩 CV를 적용한 코드를 추가했다. 실행 결과는 아직 검증되지 않았다. 아래 표는 V1/V2 탐색 기록이다.

| 단계 | 상태 | 문서 |
|---|---|---|
| EDA | 완료 | [데이터 품질과 표본 구성](v2/eda/EDA_report_ko.md) |
| 모델 입력 | 완료 | [셀과 국면 분석표](v1/cells/README.md) |
| EDA 결과 반영 전 | 완료 | [기본 모델 비교 결과](v1/models/results_v1.md) |
| EDA 결과 반영 후 | 학습 내부 비교 완료 | [결측치 처리와 특성 공학 비교](v2/reports/README.md) |
| 모델 해석 | 탐색적 해석 완료 | [국면별 주요 특성과 SHAP](v2/reports/interpretation.md) |

기본 v1은 창 27,003행·기울기 47,412행에서 법정동 64개를 시험용으로 고정했다.
학습 내부 선택은 12개 표 모두 CatBoost였고, 시험에서 모두 자치구 평균 기준선보다 RMSE가 낮았다.
일부 표의 시험 최저 오차 모델은 Ridge 또는 랜덤포레스트였다. 시험 결과를 보고 선택을 바꾸지 않았다.

2026-11-16 후속 실험은 중간 저장 후 재개해 168개 비교·840회 적합을 완료했다.
12개 표 모두 CatBoost의 선택 사양이 Ridge보다 낮은 학습 내부 CV 오차를 보였다.
SHAP와 단지 단위 1,000회 부트스트랩 해석도 완료했다. 기존 v1 시험은 다시 평가하지 않았다.
후속 결과는 탐색적이며, 최종 유형 확정과 새로운 외부 검증은 남아 있다.
