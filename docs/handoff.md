# 다음 작업 안내

## 현재 상태

EDA·셀 분석표·v1 모델 평가와 EDA 후속 비교·탐색적 해석을 완료했다.
후속 비교는 168개 사양 비교·840회 적합이며, 12개 표의 SHAP와 단지 단위 1,000회 부트스트랩을 계산했다.
후속 결과는 학습 내부 탐색이며 v1과 분리한다. 새로운 외부 검증이나 최종 유형 확정을 뜻하지 않는다.
[전체 현황](../reports/final/README.md), [EDA 후속 비교](../reports/final/followup/README.md),
[모델 해석](../reports/final/followup/interpretation.md)을 먼저 읽는다.

## 유지할 원칙

1. v5 원본과 v1 분할·분석표·예측·성능·설정을 덮어쓰지 않는다.
2. 기존 시험 동네 결과를 보고 전처리·특성·하이퍼파라미터를 고르지 않는다.
3. 후속 비교는 학습 동네와 동 단위 fold 안에서만 한다. v1 설정을 재사용하므로 후속 CV를 독립 일반화 성능으로 보고하지 않는다.
4. 주차 0값은 출처가 확정되지 않은 민감도 실험이다. 확인 없이 원본을 변경하지 않는다.
5. 결측 표시의 효과는 K-apt 등록·단지 규모와 겹친다. 시설 자체의 인과효과로 쓰지 않는다.
6. 계수 구간·SHAP는 모델 선택·표본 편향·현재값 가정의 불확실성을 모두 해결하지 않는다. 유형은 탐색 후보로 보고한다.
7. API 키는 환경변수에 두고 학습 바이너리는 커밋하지 않는다.

## 재현

[실행 순서](../src/README.md). 설정은 config/, 계산은 src/, 결과는 reports/final/에 있다.
확정 결과를 바꾸면 docs/decisions.md에 이유를 기록하고 `python tools/verify_final.py --update`로 해시를 갱신한다.

## 남은 검토

- 주차 0값·과다 주차의 외부 출처 확인.
- 현재 단지 특성을 과거에 적용한 가정과 국면별 거래 선택 편향.
- 전체 자료 EDA와 v1 시험을 열람한 점을 고려한 새로운 외부 검증 설계.
- 더 넓은 강건성: 창 폭 ±2·±4개월, 2020년 이후만, 좌표 출처별, 다음 국면 예측.
- 유형 확정 전 비선형 SHAP 의존도와 변수 간 상관 검토.
