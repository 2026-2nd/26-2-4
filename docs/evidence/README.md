# 국면 근거

국면 경계를 왜 이렇게 정했는지에 대한 근거 자료다. 수치는 모두 저장된 파일에서 다시 계산할 수 있다.

## 1. 공식 지수와 자체 지수

`data/regime/official_comparison.json`

| 지수 | 자체 지수와 월 변동률 상관 | 비고 |
|---|---:|---|
| 한국부동산원 공동주택 실거래가격지수 | 0.917 | 국면 경계의 기준 |
| 한국부동산원 주택가격동향조사 | 0.564 (1개월 지연 시 0.641) | 3~4개월 늦고 폭이 절반. 경계 판정에 쓰지 않음 |

같은 규칙을 적용한 결과(2017-01 이후):

| 지수 | 하락기 | 회복기 |
|---|---|---|
| 실거래가격지수 | 2021-11 ~ 2023-01 (−23.6%) | 2023-02 ~ 2024-07 |
| 자체 지수 | 2021-10 ~ 2023-01 (−24.1%) | 2023-02 ~ 2024-07 |
| 동향조사 | 2022-02 ~ 2023-05 (−11.3%) | 2023-06 ~ 2024-10 |

조정기(2018-11 ~ 2019-04)는 자체 지수에서만 잡힌다(−5.6%). 공식 지수는 2019-03과 2019-04 값이 같아 최소 국면 길이 판정에 걸린다. 그래서 조정기는 포함·제외 두 경우를 모두 보고한다.

## 2. 부트스트랩

`data/regime/bootstrap_regime.json` — 단지 단위로 복원 추출해 자체 지수를 200번 다시 만들고 같은 규칙을 적용했다.

| 국면 | 잡힌 비율 |
|---|---:|
| 하락기(2021~23) | 100% |
| 조정기(2018~19) | 95.5% |

## 3. 정책·기준금리

`data/external/policy_rate_timeline_2017_2026.csv` — 정책·금리 사건 51건(KB부동산 정책연혁, 한국은행 기준금리). 경계 결정에는 쓰지 않고 해석에만 쓴다. 전환점 부근에 9·13 대책(2018-09-13), 기준금리 인상 시작(2021-08-26), 규제지역 해제(2023-01-03)와 마지막 금리 인상(2023-01-13), 8·8 공급 대책(2024-08-08)이 있다.

## 4. 더 긴 기간

`data/external/rone_apt_trade_index_seoul_2006_2026.csv` — 2006년부터 같은 규칙을 적용하면 하락 2008-07~12(−18.4%), 조정 2009-10~2010-08(−8.1%), 하락 2011-03~2013-01(−11.4%), 하락 2021~23이 나온다. 실거래 원자료를 2006년부터 받으면 하락 쪽 국면을 4개로 늘릴 수 있다.
