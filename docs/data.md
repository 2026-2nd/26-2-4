## 5. 결측과 처리

| 항목 | 결측 | 이유 | 처리 |
|---|---:|---|---|
| 좌표·역·학교 | 358건 | 주소 소실 추정(재건축·번지 변경), 37개 주소 | 모델 표본에서 제외 |
| 연식_개월 | 253건 + 38건 | 준공 전 거래(분양권·입주권), 계산 불가 | 제외 |
| 세대수 | 6,795건 | 건축물대장 응답 없음 5,033(재건축 철거 단지 추정), 사용승인연도 불일치 919, 비주거 738, 조회 오류 105 | 결측 표시 변수 |
| 세대당_주차대수 | 75,555건 | K-apt에 주차 미기재 29,799, 건축물대장에 주차 미기재 38,961 등 | 결측 표시 변수. 추가 조회 대기(`data/buildreg/lots_to_query_2.csv`) |
| 사용승인일 | 9.70% | 오래된 대단지의 총괄표제부에 날짜 없음 등 | 연식은 건축년도 7월 가정 |
| 난방·복도·시공사 | 약 35% | K-apt에 없는 단지. 건축물대장에는 항목 자체가 없음 | 결측 표시 변수 |
| 동 | 68.70% | 2022년 이전 미공개 | 쓰지 않음 |

모델 입력에서 결측을 채울 때는 학습 fold 안의 통계만 쓴다(Ridge: fold 중앙값 + 결측 표시, CatBoost: NaN 그대로).

## 6. 주의

- 단지 내부값(세대수·주차·난방·복도·시공사)은 현재값을 과거 전체에 적용한 가정이다.
- `세대수_기준 = 건축물대장(번지 합계)`(17,592건)는 한 번지에 여러 단지가 있어 번지 전체 세대수다.
- 주상복합·오피스텔 혼합 건물은 세대당 주차가 3을 넘는 경우가 있다(3,350건, 비주거 주차 포함 추정). 모델에서 상한 처리를 검토한다.
- 2017~2019 원자료에는 거래 해제 표시가 없다.

## 7. 재생성

전처리는 `src/pipeline/` → `src/geo/` → `src/features/` → `src/buildreg/` 순서다(자세한 순서는 `src/README.md`).
원자료와 중간 산출물(`data/raw/` 대부분, `data/processed/`)은 Git에 없다. 재생성하려면 원자료를 받아 `data/raw/`에 두어야 한다.
