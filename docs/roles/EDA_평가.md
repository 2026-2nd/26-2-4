# EDA (탐색적 자료 분석)

## 1. 담당 역할

최종 데이터(v5)의 품질·가격 분포·국면별 표본·특성 확보율을 기술 통계로 점검하고, 모델링과 해석 단계가 알아야 할 자료의 한계를 정리한다.

범위 밖: 국면 판정, 목표 변수 y, 셀×국면 표, 분할, 모델 학습(각 담당의 일이다). `config/`와 `data/`는 읽기만 했다.

## 2. 한 일

| 무엇을 | 자료 | 코드 |
|---|---|---|
| 자료 읽기, 숫자 변환, 국면 배정 | `data/final/…_v5.csv.xz`, `config/regime.yaml` | `src/eda/load.py` |
| 결측·결측사유·중복·값 점검·이상치, 연도·자치구·국면별 건수 | 위와 같음 | `src/eda/quality.py` |
| 거래금액·㎡당가 분포, 면적·층·연식·자치구별 차이 | 위와 같음 | `src/eda/price.py` |
| 국면별 건수·분포 비교·거래 구성(선택 편향)·단지 등장 여부 | 위와 같음 | `src/eda/regime.py` |

## 4. 부딪힌 문제와 해결

| 문제 | 해결 |
|---|---|
| 세대당 주차대수가 0으로 적힌 거래 4,550건(13개 단지, 3,696세대 단지 포함). 결측으로 표시되지 않음 | 값은 그대로 두고 목록을 `tables/01_주차0_단지.csv`로 저장, 보고서 §1.4·§6에 적어 모델링 담당에게 넘김 |
| `사용승인일`에 `1970-03-00`처럼 날짜가 아닌 값 17건 | 값 점검 항목으로 추가. 원본은 고치지 않음 |
| 문서와 다른 건수: 준공 전 거래 253건(handoff는 125), 주차 > 3은 3,869건(문서는 3,350) | 보고서 §1.5에 대조표. 문서는 고치지 않고 담당자 확인으로 넘김 |
| 같은 조건 거래 묶음이 중복인지 실제 일괄 거래인지 구분 불가(호수 없음, 2017~2019 해제 표시 없음) | 지우지 않고 규모와 성격(66%가 전용 40㎡ 이하)만 기록 |
| 원시 가격을 국면끼리 비교하면 구성 변화가 섞임(하락기 ㎡당가 중앙값이 상승기②보다 높게 나옴) | 연도·자치구 중앙값 대비 상대 가격을 함께 계산하고, 보고서에 "가격지수로 읽지 말 것"을 명시 |
| 최근 3개월 거래 건수 감소가 신고 지연인지 실제 감소인지 구분 불가 | 판단하지 않고 한계로 기록 |
