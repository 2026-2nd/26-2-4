# 담당파트

팀원마다 자기 파일을 하나씩 만든다(예: `데이터수집.md`, `국면.md`, `모델링.md`, `발표.md`). 평가와 발표 준비에 쓴다.

각 파일에 들어갈 것
1. 담당 역할 한 줄
2. 한 일 (무엇을, 어떤 자료로, 어떤 코드로 — `src/` 경로를 적는다)
3. 주요 결과 (숫자는 `reports/final/` 또는 `data/` 파일에서 가져온 것만)
4. 부딪힌 문제와 해결 (예: 카카오 지오코딩 37건 실패 → 주소 소실 추정으로 제외)
5. 다른 단계에 넘긴 것 (파일 이름)
