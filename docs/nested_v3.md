# V3 — 학습 전용 EDA와 중첩 법정동 검증

2026-11-27 재설계. 과거 V1/V2는 전체 데이터 EDA 및 기존 시험 결과가 노출된 탐색적 실험으로 보존한다. 기존 64개 시험 법정동은 V3에서 학습, EDA, 튜닝, 평가 모두 제외한다. 새 외부 시험 자료는 아직 없다. V3는 독립 외부 검증이 아니라 기존 자료의 사전 탐색 한계를 인정하는 내부 중첩 검증이다.

## 고정 규칙

1. 기존 동 분할을 이용해 원자료에서 255개 학습 동만 먼저 필터링한다. 나머지 동 및 분할에 없는 동의 행을 사용하지 않는다.
2. 그 후 기존 EDA 담당 브랜치의 계산 모듈을 학습 원자료에 한해 재실행하여 결측·이상치·가격 분포·국면별 구성·특성 확보율을 다시 계산하고 셀×국면을 구성한다. V1 자체 지수는 전체 거래에서 계산되었으므로 V3는 고정 한국부동산원 공식 서울 실거래지수로 대체한다. 공식 지수의 마지막 월 2026-08을 상한으로 거래와 끝 창을 자른다. **목표 정의와 기간이 달라 V1/V2 RMSE와 직접 비교하지 않는다.** 공식 지수도 시장 거래의 집계이며 완전한 외부 독립성의 증거는 아니다.
3. 기본 15개 특성, 결측 표시, 통제변수 4개의 후보 정의는 이전 탐색에서 알려졌으므로 사전 경험에 의한 후보로 기록한다. 층은 두 방식 모두 시작 창 거래만 사용한다. 이는 시작 월 이후 일부 정보를 포함할 수 있어 미래 예측이 아닌 사후 국면 분석이다. 현재 단지 특성의 과거 적용 가정 및 거래 선택 편향은 남는다.
4. 각 국면×방식의 학습 셀에서 5-fold 외부 GroupKFold, 외부 학습 내부 3-fold GroupKFold. EDA는 각 fitting partition만 대상으로 기록한다. 사양·파라미터 선택은 내부 OOF 가중 RMSE에 의해서만 수행한다. 주차 0 결측 처리의 적용 여부도 fitting partition에서만 판단한다. 숫자 중앙값·표준화·범주 인코딩은 fitting partition에만 적합한다. CatBoost에는 외부 fold를 early stopping에 사용하지 않는다.
5. Ridge / Random Forest / CatBoost 각각 두 개의 고정 하이퍼파라미터와 3개 사양(baseline, quality, extended)을 비교한다. 계산 부담을 고려해 제한된 격자를 새로 고정하고 기존 V1 최적 파라미터는 사용하지 않는다. 기존 V2의 승인월 보완·주차 cap·로그·희소변수 제외는 V3 후보에서 제외한다(후속 민감도 연구). 주차 0의 실제 오류는 미확정이다.
6. 외부 fold는 모델 선택 완료 후 예측만 한다. 각 모델별 OOF 결과와 내부에서 선택한 전체 절차(inner_selected)의 OOF 결과 및 b0/b1 기준선을 함께 저장한다. 모델별 외부 결과를 보고 추가 튜닝하면 해당 평가도 탐색적이다.
7. 전체 학습 동에서 내부 CV로 최종 사양과 파라미터를 선택해 기록한다. 선택된 각 모델을 학습 동 전체에 재적합하고 전체 선택 모델 파일, Ridge 계수, 학습 표본 최대 1,000개 기반 CatBoost SHAP 중요도를 저장한다. 이는 탐색적 해석이며 새 외부 시험이나 유형 확정으로 보지 않는다. 저장된 OOF 예측으로 성능과 법정동 격리를 다시 확인한다.

## 실행

```bash
python -m pip install -r requirements.txt
python -m pytest -q tests/test_nested_v3.py
python src/model/nested_v3.py build
python src/model/nested_v3.py evaluate --table down_window
```

전체 실행은 GitHub Actions의 V3 nested group CV 워크플로로 수행한다. 12개 국면·방식 별 결과는 Artifacts에서 확인한다. 결과 파일은 `results/nested_v3/`에 분리되며 원본·V1·V2 확정 산출물을 수정하지 않는다. 결과는 실제 실행 및 검증 성공 이후에만 보고한다.

## 학습 전용 EDA 재실행

EDA 담당 브랜치 [eda/exploratory-analysis @ 16a267e](https://github.com/2026-2nd/26-2-4/tree/16a267e76381bd6e4f20007919e0066d51034c62)의 load, run_eda, quality, price, regime, coverage 모듈이 모델 브랜치와 동일한 Git blob임을 확인했다. 기존 전체 자료 EDA 산출물은 과거 탐색 기록으로만 유지한다. `build` 단계에서 기존 모듈의 `prepare → compute → write_tables`를 학습 원자료만 전달하여 실행하고, `results/nested_v3/eda_train/` 아래에 표·summary.json·provenance.json을 생성한다. 이 전체 학습 집합의 기술통계는 outer fold 평가에 대한 독립성을 보장하는 자료가 아니며, 모델 선택에는 각 fitting fold의 통계와 inner CV만 사용한다. 기존 고정된 세 사양, 모델, 탐색 격자, 분할, 목표 정의는 변경하지 않는다. 기존 실행은 별도 이력으로 남기고 새 커밋의 워크플로 실행을 최종 검토 대상으로 삼는다. 새로운 독립 외부 데이터는 여전히 없다.
