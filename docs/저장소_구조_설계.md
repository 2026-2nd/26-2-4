## 5. 협업 규칙

- 브랜치: `main`(확정) ← `역할/작업` (예: `model/catboost`, `docs/data-v5`). main에 직접 올리지 않고 PR로 합친다.
- PR 체크: GitHub Actions가 `pytest`와 `tools/verify_final.py`를 돌린다. 실패하면 합치지 않는다.
- config를 바꾸는 PR은 본문에 "왜 바꾸는지, 결과가 어떻게 달라지는지"를 적고 docs/decisions.md에 한 줄 추가.
- 커밋 메시지: `영역: 내용` (예: `cells: 기울기 방식 y 추가`, `docs: data.md v5 결측률 반영`).
- 대용량: 100MB 넘는 파일은 커밋 금지. 원본 데이터는 받는 방법만 docs/data.md에 적는다.
- 제안서 제출(2026-2nd/.github의 Proposal/Submission)은 별도 저장소라 이 구조와 무관.
