# 머신러닝 기반 아파트 가치형성요인 분석 프로젝트 — 연구 인수인계 및 작업 지시

## 1. 프로젝트 배경 및 현재 진행 상황

나는 금융공학과 인공지능을 공부하는 대학생으로, 지도학습 기반 머신러닝 프로젝트를 진행하고 있다.

이전 ChatGPT 대화에서 연구 논제와 주요 데이터, 모델 구성 방향을 논의했으며, 앞으로는 ChatGPT Work를 통해 실제 데이터 수집·전처리·분석·모델 개발을 진행하고자 한다.

**현재까지 완료된 작업**
- 머신러닝 지도학습 프로젝트의 연구 목적 수립
- 감정평가사 시험 및 실무에 기반한 아파트 가치형성요인 조사
- 교통·교육·자연환경·단지 내부·호실·거래시장 요인 분류
- 주요 공공데이터 출처와 API 확인
- 연구 개요 및 로드맵 수립

**아직 진행하지 않은 작업**
- 실제 API 데이터 일괄 수집
- 데이터 간 식별자 매칭 및 병합
- 공간 Feature 생성
- 머신러닝 모델 학습
- 모델 성능 평가 및 SHAP 분석

따라서 지금부터 실제 연구를 수행하는 방향으로 진행해 줘.

## 2. 확정 연구 주제

**연구 제목**

「아파트 가치형성요인의 현재 가격 및 미래 가격 상승률에 대한 예측 기여도 분석」

부제: 감정평가 실무 기반 Feature Engineering과 머신러닝을 활용한 주택 구매 의사결정 연구

### 핵심 연구 목적

아파트를 구매할 때 교통·교육·자연환경 등 입지적 조건이 우수한 아파트와, 신축·주차·단지시설 등 내부 여건이 우수한 아파트 중 무엇을 선택해야 할지 판단할 수 있도록 머신러닝 기반 의사결정 지원 모델을 구축한다.

현재 가격이 높은 아파트와 향후 상승률이 높은 아파트의 특성은 반드시 같지 않다는 문제의식에서 출발한다.

### 연구 질문

**RQ1.** 교통·교육·자연환경·단지 내부·호실 특성 중 현재 아파트 거래가격 예측에 가장 크게 기여하는 요인은 무엇인가?

**RQ2.** 이러한 가치형성요인들은 향후 3년간 아파트 가격 상승률 예측에도 유용한가?

**RQ3.** 현재 가격 예측에서 중요한 요인과 미래 가격 상승률 예측에서 중요한 요인은 일치하는가?

**RQ4.** 비슷한 구매예산과 조건에서 입지가 우수한 아파트와 단지 내부 여건이 우수한 아파트의 미래 가격 상승률 예측값은 어떻게 다른가?

궁극적으로 "좋은 아파트의 조건과 앞으로 가격이 많이 오를 아파트의 조건은 같은가?"에 답하고 싶다.

## 3. 연구 모델 구성

### 모델 A. 현재 아파트 가격 예측

- 지도학습 회귀 모델
- Target: 실제 아파트 매매 거래가격
- Input: 면적, 층수, 노후도, 입지, 교육, 공원, 단지정보, 과거 거래정보 등
- 후보 모델: Hedonic Regression, Ridge, Random Forest, XGBoost, CatBoost
- 평가 지표: MAE, RMSE, R²

### 모델 B. 미래 3년 가격 상승률 예측

- 지도학습 회귀 모델
- Target: 기준시점에서 향후 3년간 아파트 가격 변화율
- Input: 기준시점까지 관측 가능한 가치형성요인 및 과거 시장정보
- 평가 지표: MAE, RMSE, 방향 적중률, 단순 기준모델 대비 개선율

기본적인 Target 정의:

R(i,t→t+3) = [P(i,t+3) − P(i,t)] / P(i,t)

단, 동일 호실이 3년 뒤 다시 거래되지 않을 가능성이 높으므로, 동일 단지·유사 면적대 가격지수, 반복거래 기반 지수 또는 다른 적절한 방법을 검토해 정답 레이블을 구성해야 한다.

**미래 가격 레이블을 구성하는 방식의 통계적 타당성과 데이터 가용성을 먼저 검증해 줘.** 관측되지 않는 미래 가격을 임의로 생성해서는 안 된다.

초기 분석 범위는 서울시 아파트로 설정한다.

## 4. 활용할 데이터 및 Feature

기존 조사에서는 아래 데이터들의 원천자료 확보 가능성을 비교적 높게 평가했다. 단, 실제 과거 거래자료와의 결합률 및 시계열 완전성은 아직 검증하지 않았다.

### A. 실거래·호실 기본정보

**출처**

- https://www.data.go.kr/data/15126469/openapi.do
- https://www.data.go.kr/data/15126468/openapi.do

**Feature**
- 전용면적
- 거래층
- 건축연도 및 노후도

- 법정동 및 지역
- 아파트 단지명
- 실제 거래가격(Target)

시군구 코드와 계약년월을 기준으로 데이터를 조회하는 구조다.

- https://www.data.go.kr/data/15058453/openapi.do

**Feature**
- 사용승인일 기준 노후도
- 총세대수

### C. 교통여건

**출처**
- 서울교통공사 역사 좌표정보
- https://www.data.go.kr/data/15099316/fileData.do

**Feature**
- 가장 가까운 지하철역까지 거리(m)
- 반경 1km 내 지하철역 수
- 반경 1km 내 고유 노선 수

1~8호선 외에 9호선, 신분당선, 경의중앙선, 공항철도 등 누락 노선을 보완해야 한다.

### D. 교육여건

- 반경 1km 내 초등학교 수

- 반경 1km 내 고등학교 수

학교 접근성과 실제 학군 배정·교육의 질은 구분해야 한다.

### E. 자연환경

**출처**

- https://www.data.go.kr/data/15012890/standard.do

**Feature**

- 반경 1km 내 공원 대표점 기준 면적 합

공원 대표좌표 기반 계산은 실제 공원 경계 기반 접근성과 차이가 날 수 있다.

**출처**

- https://www.reb.or.kr/r-one/

**Feature**

이 데이터는 현재 가격 예측 및 미래 상승률 예측 모두에서 중요한 기준변수가 될 수 있다.

### G. 주소 좌표 변환

**출처**
- 브이월드 개발자센터
- https://www.vworld.kr/

위 주소들은 기존 조사에서 정리한 출발점이다. **현재 접근 가능 여부, 정확한 다운로드 파일, API 명세, 인증 방식, 이용조건을 공식 페이지에서 다시 검증해 줘.**

## 5. 머신러닝 분석에서 반드시 지킬 원칙

### 원칙 1. 예측 기여도와 인과적 영향력을 구분

연구의 중심은 Feature가 실제로 가격을 얼마나 인과적으로 상승시키는지 증명하는 것이 아니라, 각 Feature가 가격 예측에 얼마나 기여하는지 분석하는 것이다.

다음 방법을 고려해 줘.

- XGBoost 또는 CatBoost 기반 Feature Importance
- SHAP 및 Group SHAP
- Group Permutation Importance
- ALE 또는 SHAP Dependence Plot
- 필요시 Hedonic Regression을 활용한 조건부 가격 관계 분석

SHAP 값의 크기를 인과적 가격 효과로 해석하지 말 것.

### 원칙 2. Feature 그룹별 분석

Feature를 다음과 같이 묶는다.

1. 교통여건
2. 교육여건
3. 자연환경
4. 단지 내부요인
5. 호실 특성
6. 거래·시장요인

개별 변수별 중요도뿐 아니라 그룹별 중요도도 분석한다.

다만 특정 그룹의 Feature 수가 많거나 상관관계가 강하면 중요도 비교가 왜곡될 수 있으므로, 이를 보완하는 검증방법을 제안해 줘.

### 원칙 3. 데이터 누수 방지

미래 가격을 예측할 때 예측 기준시점 이후에 발생하거나 공개된 정보를 사용하면 안 된다.

특히 과거 유사 거래가격, 지역 가격지수, 신규 지하철역 개통, 학교 설립, 공원 개원 시점을 주의해야 한다.

모든 데이터는 가능한 한 해당 시점에 이용할 수 있었던 정보를 기준으로 구성한다.

### 원칙 4. 시간순 검증

무작위 분할만으로 미래 가격 예측 성능을 평가하지 않는다.

예측 기준시점에 따른 시간순 Train / Validation / Test 분할을 설계한다. 3년 후 상승률의 정답이 실제 관측되어 있는 기간까지만 평가한다.

단순 과거 상승률 예측, 지역 평균 상승률, 최근 유사 거래가격 등 적절한 Baseline과 성능을 비교한다.

### 원칙 5. 실험 결과를 임의로 생성하지 않기

데이터 건수, 결합 성공률, SHAP 중요도, 모델 정확도 및 상승률 예측값을 임의로 만들지 말 것. 분석하지 않은 값은 미확인으로 표시한다.

## 6. 앞으로 수행할 프로젝트 로드맵

### Phase 1. 데이터 접근성 및 연구 가능성 검증

- 기존에 확인한 공식 데이터 링크 검증
- 각 데이터의 제공기간, 파일 형식, 요청 파라미터 확인
- 실제 접근 가능한 자료 다운로드
- 서울시 일부 자치구를 대상으로 소규모 수집 테스트
- 데이터별 누락률, 주소 매칭 가능성 확인
- 미래 3년 상승률 Target을 실제로 만들 수 있는지 검증

**산출물:** 데이터 확보 현황표, Feature별 실현가능성 평가표, 검증 결과

### Phase 2. 데이터 수집 및 통합

- 서울 아파트 실거래가 수집
- K-apt 및 공간정보 데이터 확보
- 주소 표준화 및 단지 식별자 생성
- 좌표 변환 및 공간 Feature 생성
- 날짜별 과거 거래 Feature 생성
- 최종 통합 데이터셋 구축

**산출물:** 정제 데이터, 데이터 사전(Data Dictionary), 전처리 코드

### Phase 3. 현재 가격 예측 모델

- EDA 및 Target 분포 분석
- 기본 가격 예측모형 구축
- Random Forest, XGBoost, CatBoost 등 비교
- 최적 모델 선정
- SHAP으로 현재 가격 예측의 주요 가치형성요인 분석

**산출물:** 가격 예측 성능 비교표 및 Feature Importance 결과

### Phase 4. 미래 가격 상승률 예측 모델

- 단지·면적대별 미래 가격 레이블 구성
- 3년 상승률 Target 생성
- 시간순 학습·검증·테스트
- 상승률 예측모형 학습
- 단순 Baseline 대비 성능 검증
- 미래 상승률에 중요한 Feature 분석

**산출물:** 상승률 예측 성능 및 중요도 분석 결과

### Phase 5. 현재 가격과 미래 상승률의 요인 비교

- 현재 가격 모델과 미래 상승률 모델의 Feature 중요도 비교
- 입지 특성과 단지 내부 특성의 예측 기여도 비교
- 지역별 또는 가격대별 이질성 분석
- 비슷한 구매예산의 아파트 간 예측 비교 사례 구성
- 결과의 통계적 불확실성과 한계 정리

**산출물:** 최종 연구결과, 차트, 결론 및 구매 의사결정 활용방안

## 7. 최종적으로 만들고 싶은 결과물

최종 결과는 크게 두 가지다.

**첫째, 학술적인 머신러닝 연구 보고서**

현재 가격과 미래 상승률을 예측하는 데 중요한 가치형성요인이 무엇인지 분석하고, 두 모델의 변수 중요도가 어떻게 다른지 설명한다.

**둘째, 간단한 아파트 구매 의사결정 지원 프로토타입**

아파트 A와 B를 선택하면 기본 특성, 현재 가격 추정, 미래 상승률 예측, 주요 예측 기여요인, 예측 불확실성을 비교할 수 있도록 구성한다.

미래 예측이 충분히 검증되지 않은 경우 투자 추천으로 표현하지 않고, 검증된 수준에서의 참고 정보로 제시한다.

## 8. ChatGPT Work에 요청하는 첫 번째 작업

**우선 Phase 1부터 실제로 수행해 줘.**

1. 위 공식 데이터 출처를 하나씩 열어 현재 제공 여부와 접근 방법을 검증해 줘.
2. 실제 다운로드할 수 있는 CSV와 API를 구분해 줘.
3. 각 데이터의 수집 가능 기간, 규모, 주요 컬럼, 인증 필요 여부를 확인해 줘.
4. 데이터 간 결합에 사용할 식별자와 좌표정보 확보 방식을 구체화해 줘.
5. 서울 일부 자치구를 대상으로 접근 가능한 데이터의 샘플 수집 및 결합 가능성을 검증해 줘.
6. 특히 미래 3년 가격 상승률 Target을 실제 자료로 구성할 수 있는지 우선 판단해 줘.
7. 확인 결과를 바탕으로 데이터 수집·전처리·모델링 코드를 작성하고, 후속 단계에 사용할 작업 파일을 정리해 줘.

데이터 수집에 인증키가 필요하거나 접근이 제한되는 경우에는 그 사실을 알려주고, 가능한 공개 대체자료를 먼저 검토해 줘.

자료 접근이 가능하면 확인에 그치지 말고 실제 수집과 검증까지 진행해 줘. 접근할 수 없는 데이터의 수집이나 분석이 완료된 것처럼 표현하지 말아 줘.

**전체 연구 논제는 이미 확정되어 있으므로 임의로 변경하지 말고, 실현가능성이 낮은 부분은 명확한 근거를 제시한 뒤 대체 방안을 제안해 줘.**

최종적으로는 지금까지 완료한 작업, 생성된 파일, 검증된 사실, 남은 문제, 다음 단계의 실행계획을 명확하게 기록해 줘.
