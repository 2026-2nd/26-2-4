# 2017~2026 확장 준비 (2026-11-03)

## 1. 받아야 할 원자료 (사용자)
국토교통부 실거래가 공개시스템 [조건별 자료제공](https://rt.molit.go.kr/pt/xls/xls.do)에서 연도별로 1개씩, 총 3개를 받는다.
- 조건: 실거래구분 아파트(매매) / 주소구분 지번주소 / 시도 서울특별시 / 시군구 전체 / 계약일자 YYYY-01-01 ~ YYYY-12-31 / CSV
- 연도: 2017, 2018, 2019
- 파일명은 아무거나 괜찮다. 다운로드 전 화면에 표시되는 **조회 건수를 연도별로 메모**해 두면, 기존 2020~2026과 같은 방식으로 공식 건수와 대조한다.
- 받은 파일을 `기계학습팀플` 폴더에 넣는다.

## 4. 국면 판정 규칙 (사전 고정, `src/regime/turning_points.py`)
1. 월간 서울 아파트 지수의 3개월 중심 이동평균
2. ±6개월 안에서 최고·최저인 달을 정점·저점 후보로 잡음
3. 정점·저점을 교대로 남김
4. 한 국면은 최소 6개월, 한 순환은 최소 15개월
5. 정점→저점 하락률 10% 이상이면 하락기, 3~10%면 조정기, 3% 미만이면 무시
6. 저점 이후 직전 낙폭의 50%를 회복할 때까지 회복기, 그 뒤는 상승기
7. 단지·면적 셀 변화율 계산 창은 정점 ±3개월, 저점 ±3개월

**현재 2020~2026 자체 지수에 적용한 결과:** 상승기 2020-01~2021-09 / 하락기 2021-10~2023-01 (정점 대비 −24.4%) / 회복기 2023-02~2024-08 / 상승기 2024-09~2026-10.
- 2023-10~2024-01의 소폭 하락은 국면 길이 규칙(6개월 미만)에 따라 국면으로 인정하지 않았다.
- 이 결과는 앞서 대화에서 눈으로 잡았던 경계(하락기 2021-11 시작, 회복기 2024-03까지)와 다르다. **앞으로는 이 규칙 결과를 쓴다.**
- 한국부동산원 월간 지수를 받으면 같은 규칙을 적용해 대조한다.

1. 원본 형식·범위·해시 검사, 공식 건수 대조 → 2017~2026 통합

4. 실시간 지수 재추정(2017~) → 국면 규칙 적용
5. 2018~19 조정이 규칙상 조정기로 잡히는지 확인
6. 국면별 단지·면적 셀 변화율 데이터셋 생성
7. 첫 번째 검증: 이전 상승기 패턴으로 다음 상승기 예측
