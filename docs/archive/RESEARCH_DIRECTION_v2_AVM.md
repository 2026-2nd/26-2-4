# 연구 방향 v2 (2026-11-02 확정) — 실무형 거래사례비교모형 vs 머신러닝 AVM

이 문서는 이전 방향(가치형성요인 기여도 / 미래 3년 상승률)을 대체한다. 전처리 결과는 계속 사용한다.

## 확정 사항 (사용자 결정)
- 제목: 「감정평가 실무 기반 거래사례비교모형과 머신러닝 자동가치평가모형(AVM)의 아파트 가격 추정 성능 비교 연구 — 거래사례의 풍부도에 따른 AVM의 대체 가능성을 중심으로」
- 대상: 서울 아파트 매매 실거래. 1행 = 거래 1건. Target = 실제 거래가격(평가 기준시점의 시장가격 추정).
- 미래 3년 상승률 예측은 제외.
- Model A: 「감정평가에 관한 규칙」·「감정평가 실무기준」의 거래사례비교법을 자동화한다. 절차는 사례 선정 → 사정보정 → 시점수정 → 가치형성요인 비교 → 비준가액. 단순 평균이나 KNN 모형으로 만들지 않는다. 보정계수를 임의로 정하지 않고, 머신러닝으로 과최적화하지도 않는다. 산출 과정은 추적 가능해야 한다.
- Model B: XGBoost/CatBoost(+RF·선형 benchmark). 실거래 기반 Feature 우선.
- 풍부도: 이전 12개월·동일 단지·전용 ±5% 거래 수로 정의하고 0 / 1~2 / 3~5 / 6+로 나눈다(잠정). Model A가 검색 범위를 넓혀도 풍부도 정의는 고정한다.
- 평가: MAE·RMSE·MdAPE, ±5/±10% 적중률, Coverage, 구·가격대·풍부도·시점별 안정성, 미등장 단지 일반화, 대응표본 bootstrap·비열등성(한계는 사전 설정), 단지 클러스터 고려.
- 시간순 분할. 평가 기준시점 이전 정보만 사용. 테스트 기간 가격은 튜닝·보정에 쓰지 않는다.
- 수치를 임의로 생성하지 않는다. 실무 감정평가 전체를 대체한다고 주장하지 않는다.

## 검증 결과 (2026-11-02, 전처리 데이터 356,087행으로 실제 계산)
1. **법적·실무 구조 확인**: 공개된 경매 감정평가서(구분건물)가 규칙 제16조를 근거로 거래사례비교법을 적용했다. 산식은 사례 단가 × 사정보정(1.000) × 시점수정(기준시점 지수/거래시점 지수, 한국부동산원 월간 매매가격지수) × 면적비교 × 가치형성요인(단지외부·단지내부·호별·기타 요인)으로 계획서 산식과 같다. 이 사례는 아파트가 아닌 다세대이므로 아파트 평가서를 추가로 확인해야 한다. 법령 원문은 law.go.kr에서 대조해야 한다.
2. **공개 지연**: 부동산 거래신고 기한은 계약일부터 30일이다(2020-02-21 시행, 이전 60일). 평가 기준시점에 아직 신고되지 않았을 거래를 비교사례로 쓰면 누수가 생긴다. 30일 지연을 적용하면 사례 0건 비율이 11.3%에서 14.5%로 늘어난다. → 풍부도와 Model A 사례 선정 모두 "계약일 + 30일 < 평가 기준시점" 기준을 권고.
3. **풍부도 분포** (30일 지연 기준): 0건 14.5%, 1~2건 15.0%, 3~5건 15.4%, 6건 이상 55.1%. 연도별 편차가 크다(0건 비율: 2020년 26.0%, 2022년 24.5%, 2025년 7.6%, 2026년 8.9%). 테스트 기간을 2026년으로 잡으면 0건 그룹 표본이 작아져 H3 검정력이 낮다.
4. **H1 순환 문제**: 풍부도 정의와 Model A 1단계 선정 기준이 같아서, "사례가 적을수록 A의 오차가 커진다"는 결과가 정의상 거의 보장된다. → H1은 증가 폭을 추정하는 문제로 바꾸고, 사례의 유사도(거리·면적 차·시점 차)를 별도로 측정할 것을 권고.
5. **좌표 결측이 0건 그룹에 집중**: 단지 좌표가 없는 비율은 0건 그룹 53.8%, 1~2건 34.2%, 3~5건 19.2%, 6건 이상 9.3%이다. Model A의 "인근 단지" 확장과 단지외부요인 비교에는 좌표가 필요하므로, 지오코딩 없이는 H3의 핵심 집단에서 A의 Coverage가 인위적으로 낮아진다.
6. **사정보정 자료**: 거래유형(중개/직거래) 필드는 2021-11-01 계약분부터만 있다. 2021-10 이전은 모두 '-'이다. 직거래는 13,100행(3.7%). 직거래를 근거로 보정할 경우 기간에 따라 적용 범위가 달라진다. → 보정률을 부여하지 않고 "사례 제외 후보 플래그"로만 쓰고, 기간 제약을 명시할 것을 권고.
7. **Model B와 비교사례 정보**: B에 최근 유사거래가와 단지 식별정보를 넣으면 B도 비교사례에 기반한 모형이 된다. → B1(비교사례 Feature 없음)과 B2(포함)를 나눠 비교하면 RQ3 해석이 명확해진다. 미등장 단지 테스트에서는 단지 식별정보를 쓸 수 없다.
8. **시점수정 지수의 가용 시점**: 한국부동산원 지수는 발표 시차가 있으므로, 평가 기준시점에 발표돼 있던 월까지만 써야 한다. 자체 지수를 만든다면 30일 지연을 적용한 실시간 방식으로 만들어야 한다.
