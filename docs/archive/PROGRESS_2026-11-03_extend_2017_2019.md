# 2017~2019 확장 결과 (2026-11-03)

## 결과
- 2017~2026 서울 아파트 매매 **617,592건** (2017 104,928 / 2018 81,579 / 2019 74,998 + 기존 2020~2026 356,087). record_id는 모두 고유하다.
- 원자료: 사용자가 받은 공식 조건별 CSV 3개. 검색조건(아파트 매매·지번주소·서울 전체·연도 전체), 25개 자치구, 계약일 범위, 컬럼 구성을 검사했다. 원본과 해시는 `data/raw/seoul_sales_2017_2019/`에 보관한다.
- **공식 조회 건수 대조는 아직 하지 않았다.** 다운로드 화면의 연도별 건수를 알려 주면 기록한다.

## 재현 방법과 검증
- `src/extend_2017_2019.py`: 기존 단계 코드를 그대로 불러 쓴다.
  - 원본 검사 → record_id/fingerprint → 호실 → 지역·시간 → 단지 연결 v1 → v2 규칙 → v3 규칙 → 정적 가정 정책 v3
- 단지 조합 8,166개 중 **7,689개는 2020~2026의 기존 v3 판정을 재사용**했다. 2017~2019에 처음 나온 477개만 같은 규칙 코드로 판정했다.
  - 결과: 미해결 457, v3 규칙 연결 14(후보 교정 1 포함), v2 유지 6. 목록은 `reports/seoul_sales_2017_2019/crosswalk_new_keys_2017_2019.csv`.
- **재현 검증:** 같은 코드로 2020년 원본(80,858건)을 다시 처리했다. 기존 결과와 82개 컬럼이 전 행 일치했다(수집시각 제외).
  - 유일한 차이는 `static_assumption_version` 표기다. 기존 파일은 v3 재처리 대상이 아닌 행에 '2.0'이 남아 있고, 새 코드는 '3.0'을 쓴다. 판정 내용은 같다.
- 역·학교 Feature v2 (`src/build_access_features_v2.py`):
  - 2017~2025 개통 이벤트 100개 역-노선을 반영했다.
  - 설립일 2016년 이후 학교는 설립일을 개교일 대용으로 썼다.
  - 폐교 목록 v2: 초등 8곳, 중·고 12곳.
  - **2020~2026 행의 값은 v1과 전부 동일하다.**
- 시점 확인 예: 에스케이북한산시티는 2017년 미아역 1,523m → 2018년부터 솔샘역 266m(우이신설선 2017.9). 우성4차는 2018년까지 잠실새내 1,024m → 2019년 삼전역 422m(9호선 3단계 2018.12).

## 주의
1. **2017~2019 원자료에는 해제 표시가 없다.** 이후 해제된 거래가 섞여 있을 수 있다. 2020년 이후와 정제 수준이 다르므로 국면 비교에서 한계로 적는다.
2. 단지 내부값의 "변경 없음 가정"이 2017년까지 늘었다. 장기 비교에는 면적·층·연식·위치·세대 규모 위주로 쓰는 것을 권한다.
3. `contract_time_index`(작업용 CSV)는 2020-01=0 정의를 유지해 2017~2019가 음수다. 한글 데이터셋의 `계약시점_월순번`은 2017-01=0으로 다시 맞췄다.
