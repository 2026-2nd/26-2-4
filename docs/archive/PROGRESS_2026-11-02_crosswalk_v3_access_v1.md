## 3. 교통·교육 원천과 시점 이력
`config/access_history/README.md`에 원천·해시·가정을 기록했다.
- **역 좌표**: 국가철도공단 레일포털 `전체_도시철도역사정보_20260630.xlsx`(1,099행)을 내장 브라우저로 받아 서울 주변 범위 691행을 보관했다. 브라우저에서 계산한 해시와 컨테이너 파일 해시가 일치한다. 서울 밖 인접역(하남·구리·광명·부천·고양·과천·성남 등)도 포함한다.
- **개통 이력**: 원천에 개통일이 없어 2020년 이후 개통 이벤트 44개 역행(미사·하남, 강일, 석남, 남위례, 진접선, 신분당 신사~강남, 신림선 11역, 서해선 대곡~소사·일산, 별내선, 인천1 검단)과 GTX-A 승강장 3개(좌표는 같은 역의 다른 노선 좌표로 대체)를 반영했다. 출처는 미래철도DB 1곳(2차 자료)이다. 공식 고시와의 대조가 다음 할 일이다.
- **초등학교**: 학교표준데이터(전국, 기준 2026-10-01) 범위 내 운영 초등학교 1,595곳 + 폐교알리미 GIS에서 받은 2018년 이후 폐교 초등학교 7곳(서울 염강초 2020, 화양초 2023 포함)의 좌표. 폐교 원천에는 연도만 있어 3월 1일 폐교로 가정했다. 설립일 2019년 이후 학교는 설립일을 개교일 대용으로 사용했다.

## 4. 새 Feature (`src/build_access_features.py`)
출력: `data/processed/seoul_sales_2020_2026/seoul_apt_sales_2020_2026_crosswalk_v3_access_v1.csv` (356,087행·92컬럼, SHA256 `1319998a…b308`).
- `nearest_operating_station_distance_m`, `operating_line_count_1km`, `nearest_elementary_school_distance_m`(+이름·근거·상태·사유 컬럼). 계약일 기준으로 개통일 ≤ 계약일 < 폐쇄일인 시설만 포함한다.
- 노선은 서비스 노선 단위로 묶었다(2호선 지선 = 2호선, 경원선 용산~왕십리 = 경의중앙, 일산선 = 3호선, 진접·안산과천 = 4호선, 별내선 = 8호선 등).
- 계산 281,229행, 결측 **74,858행(21.02%)**: 단지 좌표가 없는 행(미연결 단지)이며 0으로 채우지 않았다.
- 중앙값: 역 478m, 초등학교 295m. 1km 내 노선 0개는 24,700행이다.
- 점검: 신림선 인근 단지는 2022-05-28 이전과 이후로 최근접역이 바뀐다(예: 보라매 546m → 서울지방병무청 380m).
- 주의 플래그: 위치 전용 연결 47,547행, 개교일 대용 4,813행, 폐교 연도 1~2월 모호 613행, GTX 대체 좌표 1km 이내 1,065행. 단지 좌표는 현재 K-apt 대표점이고, 거리는 직선 Haversine 거리(보행거리 아님)이다.
