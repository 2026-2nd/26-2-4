## 2026-11-27 — V3 중심으로 정리

모델 실험 V1은 `old/v1/`, V2는 `old/v2/`로 모았다. 전체 자료 EDA는 V2의 배경
자료로 `old/v2/eda/`에 두고, 학습 전용 EDA 계산 모듈은 V3가 재사용하도록 `src/eda/`에 유지한다.
전용 코드·설정·도구도 해당 버전으로 옮겼다. [이동표](../old/relocation.json)에 이전 경로를 기록했다.

V3는 `src/model/common.py`, `design.py`로 공통 함수를 분리하여 과거 실험 모듈을 import하지 않는다.
V3 동 분할은 `data/splits/`에 원래 분할과 동일한 바이트로 고정하고 출처를 기록했다.
과거 숫자 결과·예측·JSON·그림 260개는 바이트가 동일함을 확인했다.
기존 `old/v1/sha256.json`은 그대로 보존하고 현재 경로의 해시는 `tools/frozen_files.json`으로 관리한다.

루트 README와 `src/README.md`, `docs/handoff.md`는 V3 결과와 실행 순서를 먼저 보여준다.
공통 원자료·시설 이력·데이터 처리 모듈의 v1/v2 표기는 모델 실험 버전과 달라 이동하지 않았다.
