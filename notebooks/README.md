# 노트북

노트북은 **설명과 시각화만** 한다. 계산은 `src/`가 하고, 노트북은 `data/`와 `reports/final/`의 결과를 읽어서 보여준다. 노트북 안에서 원자료를 다시 처리하지 않는다.

| 노트북 | 내용 | 상태 |
|---|---|---|
| `01_데이터_파이프라인.ipynb` | 수집 → 단지 연결 → 좌표 → 건축물대장, 단계별 결측률 변화 | 예정 |
| `02_EDA.ipynb` | 자료 품질, 가격 분포, 국면별 표본·거래 구성, 특성 결측 (`reports/eda/`를 읽음) | 완료 |
| `03_국면.ipynb` | 자체·공식 지수, 전환점, 정책·금리 타임라인 | 예정 |
| `04_모델링_결과.ipynb` | 성능표, 계수·SHAP, 특성 유형표 | 예정 |

커밋 전에 출력이 너무 크면(그림 여러 장) 출력을 지우고 커밋한다. README에 쓸 그림은 `reports/final/figures/`에 png로 저장한다.
