# 교통·교육 시점 이력 원천 (v1, 2026-11-02 수집)

## 역
- 기준 좌표: 국가철도공단 레일포털 `전체_도시철도역사정보_20260630.xlsx` (https://data.kric.go.kr/rips/M_01_01/detail.do?id=32, data.go.kr 15013205). 원본 xlsx SHA256 `cdf1d84a7e5c898b2aacd622783ba8ba9af35c40bee0561dc97d55ce8e063f94`(1,099행). 서울 포함 위도 37.30~37.80·경도 126.60~127.35 691행만 `data/raw/kric_stations_bbox_20260630.csv`로 보관(SHA256 `be4c39d1…14d7`, 내장 브라우저 계산값과 일치 확인).
- 원천에 개통일 없음. `rail_open_events_v1.csv`의 2020-01-01 이후 개통 이벤트만 날짜 적용하고, 나머지 행은 2020-01-01 이전부터 운영으로 가정(`assumed_open_before_2020`). 이벤트 출처는 미래철도DB 단일 2차 출처이며 공식 고시 대조는 아직 안 함.
- KRIC 원천에 GTX-A가 없어 `rail_added_platforms_v1.csv`에 3개 승강장을 추가했다. 좌표는 같은 역 다른 노선 좌표 대용(`coordinate_proxy_colocated_station`).
- 알려진 누락: 경의중앙선 양원역 등 일부 역이 원천에 없음. 2020~2026 폐역·이전은 미래철도DB에 없음(전수 공식 확인 아님). 교외선(2025-01-11) 역 원천 미포함.
## 초등학교
- 운영 학교: 학교표준데이터(data.go.kr 15021148, 기준 2026-10-01) 전국. 설립일(FOND_DATE)≥2020인 학교는 설립일을 개교일 대용으로 사용(`fond_date_as_open_proxy`).
- 폐교: 폐교알리미(한국교육시설안전원) GIS 레이어에서 위 범위·2018년 이후 폐교 초등학교 7곳 좌표 수집. 원천은 폐교 연도만 제공 → 3월 1일자 폐교로 가정(`closed_year_assumed_mar01`). 해당 연도 1~2월 거래는 플래그.
- 학교 이전·통폐합 위치 변경 이력은 미구축.
