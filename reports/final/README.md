기본 v1은 창 27,003행·기울기 47,412행에서 법정동 64개를 시험용으로 고정했다.
학습 내부 선택은 12개 표 모두 CatBoost였고, 시험에서 모두 자치구 평균 기준선보다 RMSE가 낮았다.
일부 표의 시험 최저 오차 모델은 Ridge 또는 랜덤포레스트였다. 시험 결과를 보고 선택을 바꾸지 않았다.

2026-11-16 후속 실험은 사용자 요청으로 중간 저장했다. 기존 v1 시험은 다시 평가하지 않았다.
모델 해석·최종 유형 확정·새로운 외부 검증은 완료하지 않았다.
