# 호실 Feature 반영 결과

작업일: 2026-11-02. 연구 명세 v1.2의 기본 호실 변수 3개를 거래 레코드별로 반영했다. 필요한 원천 항목이 이미 확보한 국토부 거래 CSV에 있어 추가 API 호출은 하지 않았다. 상대층은 대체 사양 후보로 유지하며 생성하지 않았다.

## 산출 파일

- `data/processed/seoul_sales_2020_2026/seoul_apt_sales_2020_2026_unit_features.csv`: 해제 제외 거래 356,087행, 원본 22컬럼에 Feature·추적·품질 10컬럼을 추가한 UTF-8 BOM CSV.
- `reports/unit_features/rows_for_review.csv`: 검토 대상 77행. 5건은 연식 결측, 72건은 지하/0층 검토 표시.
- `reports/unit_features/summary.json`: 입력·출력 해시, 행수, 변수 범위·결측·검토 사유.
- `reports/unit_features/year_summary.csv`: 연도별 반영 건수와 품질 상태.
- 재현 코드: `src/build_unit_features.py`.

## 변수 정의와 실측 결과

| 필드 | 정의 | 유효값 행수 | 결측 | 관측 범위 |
|---|---|---:|---:|---|
| `exclusive_area_m2` | 거래 원자료의 전용면적을 숫자로 변환. ㎡, 양수·유한값 검사 | 356,087 | 0 | 10.156~317.36㎡ |
| `transaction_floor` | 거래 원자료의 층을 정수로 변환. 음수·0은 삭제하지 않고 검토 표시 | 356,087 | 0 | -3~68층 |
| `building_age_years` | **계약연도-건축연도**. 계약시점 기준 연 단위 근사 연식 | 356,082 | 5 | 0~65년 |

정확한 사용승인일을 사용하지 않았으므로 유효한 연식의 `age_basis`는 모두 `build_year_approx`다. 예: 2020년 계약·2001년 건축이면 19년이며 수집연도 기준으로 계산하지 않는다. 건축연도만 있으므로 정확한 경과 만년수나 해당 연도 내 준공 전후는 판별할 수 없다.

건축연도가 계약연도보다 늦은 5건은 사유 `build_year_after_contract_year`와 함께 연식을 결측 처리했다. 원자료를 보고 임의로 연도를 수정하거나 연식을 0으로 바꾸지 않았다. 실제 신고·정정·거래 성격 등의 근거를 확인하기 전 오류 원인을 확정하지 않는다. 나머지 Feature와 원본 거래행은 보존했다.

음수 또는 0층 72건은 `nonpositive_floor_review`로 표시했다. 지하층 자체를 오류로 단정하거나 삭제하지 않았다. 원층 표기의 의미와 분석 포함 여부를 후속 검토한다.

## 행수·추적성 검증

- 원본 373,718행 = 해제 표시 제외 17,631행 + 출력 356,087행.
- 출력 거래 356,087행의 `record_id`가 모두 유일하다. 호실 변수 결측을 이유로 삭제한 거래는 없다.
- 상태: `complete` 356,010행, `complete_with_review` 72행, `incomplete` 5행.
- `record_id`는 원본 연도 파일의 SHA256과 해당 파일 내 데이터 행 순번으로 생성했다. 실제 거래의 공인 고유번호가 아니며 재수집한 스냅샷과 자동 동일시하지 않는다.
- `record_fingerprint`는 공개 속성 비교용이며 같은 값이라는 이유만으로 중복 거래를 삭제하지 않는다.
- `source_row`는 원본 파일에서 머리말·헤더를 제외한 데이터 행 순번이다. 해제 거래도 순번에 포함한다.
- `contract_date`는 YYYY-MM-DD로 변환했다. 원본 건축년도·계약년월·계약일·층·면적·가격 등을 그대로 보존했다.

## 모델 입력과 해석 주의

이 파일은 원자료를 함께 보존한 거래 테이블이다. 가격·단지명·건축년도 원값·원본 번호 등 모든 컬럼을 모델 입력으로 사용하면 안 된다. 명세에 지정한 Feature만 명시적으로 선택한다. 현재 거래금액은 가격모델 Target이며 입력에서 제외한다. 연식과 원 건축연도를 기본 입력에 함께 넣지 않는다.

명세의 과거 기준 원칙은 연식을 각 계약일 기준으로 계산하는 데 적용했다. 원자료는 수집 당시의 최신 수정본이므로 당시 최초 공개값과 동일하다는 증거는 아니다. 면적·층과 건축연도의 원천 정확성도 신고자료 이상의 검증을 완료한 것은 아니다.

호실 데이터 변환 경계 검사는 인공 fixture 5개(계약연도 연식, 미래 건축연도, 불가능한 날짜, 지하층 보존, 비유한/0 면적)로 확인했다. fixture는 연구자료와 분리되어 있다. 실제 출력의 행수·유일 ID·연도별 합계와 결측 건수도 대조했다.

현재 완료 범위는 호실 기본 변수 3개이다. 단지 매칭·단지 내부 변수·교통·교육 결합·상관관계 및 VIF·모델 학습은 이번 작업에서 실행하지 않았다.
